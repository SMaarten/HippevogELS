Zo werkt bestellen

  1. Kies je juweel en leg het in je mandje.
  2. Verstuur je bestelling met je naam, e-mailadres en leveringswijze.
  3. Els bevestigt binnen 1–2 dagen dat je stuk nog beschikbaar is en stuurt de betaalgegevens.
  4. Betaal via overschrijving{% if site.data.winkel.iban != "" %} op {{ site.data.winkel.iban }}{% endif %}. Zodra de betaling binnen is, wordt je juweel verzonden of kan je het afhalen.

Verzending

Verzending binnen België kost € {{ site.data.winkel.verzendkosten | replace: '.', ',' }}{% if site.data.winkel.gratis_verzending_vanaf > 0 %} en is gratis vanaf € {{ site.data.winkel.gratis_verzending_vanaf }}{% endif %}.{% if site.data.winkel.afhalen_mogelijk %} Afhalen kan ook: {{ site.data.winkel.afhaaladres }}.{% endif %}

Waarom geen directe betaling?

Elk stuk is uniek. Door eerst te bevestigen, ben je zeker dat niemand anders jouw juweel tegelijk koopt.

Retour

Niet tevreden? Je hebt 14 dagen herroepingsrecht. Stuur het juweel onbeschadigd terug en je krijgt je geld terug (oorbellen enkel indien ongedragen, om hygiënische redenen).
